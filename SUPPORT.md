# Support

Tara is maintained as a beta open-source project.

Before opening an issue:

1. confirm the problem occurs on the newest published beta;
2. check the README, roadmap, and existing issues;
3. remove recordings, transcripts, credentials, database files, email addresses,
   and other personal information from logs or screenshots;
4. include the Tara version, Windows version, capture mode, expected behavior,
   actual behavior, and minimal reproduction steps.

Security reports must follow the private process in [SECURITY.md](SECURITY.md).

Support is best-effort. The project does not provide service-level guarantees,
cloud recovery, legal advice about recording consent, or compatibility guarantees
for modified binaries and untested audio hardware.
