# Branding and project identity

## Name and logo

Tara is an independent local-first meeting-assistant project. It is not
affiliated with, endorsed by, or connected to any similarly named product,
company, or service.

The AGPL license covers the repository's source code and original artwork, but
does not grant permission to imply that a modified build is an official Tara
release. Forks are encouraged to use a distinct product name, application ID,
and logo when distributing binaries.

## Official builds

Only releases published from `Pilvik1/tara-local-meeting-assistant` by the
maintainer should be described as official Tara builds. Third-party builds must
state that they are modified or independently distributed.

Before broad commercial distribution, the Tara name and visual identity should
receive a separate trademark-clearance review. This document is a naming policy,
not a claim that trademark registration or clearance has already occurred.
